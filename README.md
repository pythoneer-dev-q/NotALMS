# NotALMS

NotALMS - LMS для интерактивных курсов, задач, новостей и учебного прогресса.

## Возможности

- Курсы, уроки и единый редактор контент-блоков.
- Блоки текста, списков, изображений, видео, кода и формул LaTeX.
- Задания по биологии и математике: сложение, вычитание, умножение и деление.
- Прогресс, рейтинг, поиск пользователей и публичные профили.
- Telegram-бот: привязка аккаунта и вход по одноразовому коду.
- Управление курсами, новостями, поддержкой и пользователями.
- Блокировка аккаунта с отдельной страницей доступа.
- Cloudflare Turnstile для входа и регистрации, если заданы ключи.

## Стек

- Python, FastAPI, Motor, MongoDB.
- Чистый HTML/CSS/JavaScript.
- JWT, bcrypt через `passlib`.
- aiogram для Telegram-бота.

## Структура

```text
back/server/database/  # MongoDB-репозитории
back/server/handlers/  # REST API, авторизация, CAPTCHA и rate limit
back/server/tasks/     # генераторы и валидаторы заданий
front/assets/pages/    # HTML: public, account, course, news, admin
front/assets/static/   # общие CSS, JS и медиа
front/server/          # роутер фронтенда
scripts/               # установка и обслуживание
docs/                  # эксплуатационная документация
```

## Запуск

```bash
cp .env.example .env
docker compose up -d --build
```

В `.env` задайте как минимум `SECRET_KEY` и `ADMIN_SECRET`; `BOT_TOKEN` нужен для Telegram-бота. На Linux доступен интерактивный установщик:

```bash
bash scripts/install.sh
```

Он предлагает Docker либо venv + systemd, создаёт или обновляет `.env`, устанавливает зависимости и сохраняет безопасные фоллбеки новых настроек.

## CAPTCHA

Turnstile выключен, пока оба значения пустые:

```env
TURNSTILE_SITE_KEY=
TURNSTILE_SECRET_KEY=
CAPTCHA_SUSPICIOUS_RPS=15
```

При пустых ключах вход и регистрация работают без виджета и лишнего отступа. При включении сервер проверяет одноразовый токен через Cloudflare; auth-запросы выше 15 RPS с одного IP получают требование CAPTCHA. Инструкция: [docs/turnstile.md](docs/turnstile.md).

## Демо-курс математики

`math_arith_basics` уже создан в MongoDB как обычный опубликованный курс: четыре урока и четыре задания по сложению, вычитанию, умножению и делению.

Содержимое курса **не хранится в Python-коде**. Изменяйте его через редактор курса: MongoDB - единственный источник данных для теории, уроков и заданий.

## Основные API

Все методы имеют префикс `/v1`.

- `POST /register`, `POST /login` - регистрация и вход.
- `GET /captcha/config` - публичная конфигурация Turnstile без секрета.
- `GET /me`, `PUT /me/password` - профиль и смена пароля.
- `GET /leaderboard`, `GET /users/search` - рейтинг и поиск.
- `GET /news` - опубликованные новости.

## Безопасность

- Пароли хранятся только как bcrypt-хеши.
- Удалённые логины резервируются и не могут быть использованы повторно.
- При блокировке пользователь попадает на `/blocked`; защищённые методы запрещают доступ по статусу в БД.
- Telegram-привязка и причина блокировки не выдаются в публичный профиль.
